## Overview

MOGAD is an autoimmune inflammatory demyelinating disorder of the central nervous system that has been established as a distinct entity from multiple sclerosis (MS) and aquaporin-4-IgG neuromyelitis optica spectrum disorders (AQP4-NMOSD). This repository contains a comprehensive literature review focusing on pediatric MOGAD.

## Key Findings Summary

| Parameter | Value |
|-----------|-------|
| Prevalence | 1.3-2.5 per 100,000 |
| Pediatric proportion | 30-50% of all MOGAD |
| Mean onset age | 6-8 years |
| Most common phenotype (<5y) | ADEM (81%) |
| Relapse rate (long follow-up) | 50-72% |
| Visual recovery rate | >95% |
| EDSS ≥6 at long-term follow-up | 7% |

## Key Clinical Takeaways

### Treatment Recommendations
- **Early immunotherapy (<7 days)**: 6.7-fold reduced relapse risk
- **Steroid taper ≥5 weeks**: 6.7-fold reduced relapse risk
- **Monthly IVIG**: Reduces ARR from 2.16 to 0.51

### Prognostic Factors

| Favorable | Unfavorable |
|-----------|-------------|
| Optic nerve involvement | Spinal cord involvement |
| Early immunotherapy | MDEM phenotype |
| Seroconversion to negative | Persistent seropositivity |
| Monophasic course | High MOG-Ab titer |
